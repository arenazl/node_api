# Project Context: MQ Importer API

This project is a Node.js Express API for importing and processing MQ messages.

## Key Technologies

- **Backend:** Node.js, Express
- **Package Manager:** npm

## Commands

Use these exact commands. Do not guess.

### Root Directory

- **Install all dependencies:** `npm install`
- **Run dev server:** `npm run dev`
- **Start server:** `npm start`
- **Run tests:** `npm test`
